# RASAVIDYA AI

Evidence-led research infrastructure for Rasashastra manuscripts, historical claims about metal transformation, modern materials science, and nuclear-evidence assessment.

> Research scaffold: the API and database are separate from the Floot frontend. No claim is considered verified merely because it appears in a historical text. No executable toxic-metal recipes are provided.

## Status

This repository was initially empty. The first commit establishes the project; API modules, database models, ten-agent registry, tests, and deployment configuration are being added next.

## Research principles

- Preserve source provenance, page/verse references, OCR uncertainty, and competing translations.
- Distinguish alloying, amalgamation, gilding, compounds, purification, and elemental transmutation.
- A gold-coloured sample is not proof of elemental gold; chemical reactions do not change atomic number.
- Claims of nuclear transmutation require rigorous composition/isotope evidence, contamination controls, and independent replication.
- Do not publish hazardous executable procedures involving mercury, arsenic, toxic reagents, or radiation.
